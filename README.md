## **Descrição do Projeto**
Este repositório apresenta o desenvolvimento do Projeto Integrador (PI) do 4º semestre, cujo propósito foi criar um **protótipo funcional de e-commerce para farmácias**.  
O sistema simula a navegação de um usuário em uma plataforma de compras, incluindo visualização de produtos, detalhes, carrinho e fluxo básico de compra.

---

## **Objetivo Acadêmico**
O projeto visa aplicar na prática os conteúdos estudados ao longo do semestre, reforçando conceitos fundamentais de desenvolvimento web e organização de interfaces, além de promover a integração entre teoria e prática por meio da construção de um sistema funcional.

---

## **Tecnologias Utilizadas**
- **HTML5**  
- **CSS3**  
- **JavaScript**  
- **Node.js (Express)** para simulação simples de backend

---

## **Escopo do Sistema**
- Exibição de farmácias e produtos  
- Visualização de detalhes de itens  
- Cadastro e login de usuários  
- Adição e gerenciamento de produtos no carrinho  
- Processo básico de checkout  

---
